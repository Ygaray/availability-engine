<objective>
Fix the confirmed packaging bug (D-05): the wheel currently ships `availability_engine`'s
Python source but silently drops the repo-root `alembic/` migration tree, so a fresh
git-tag-pinned install cannot bootstrap a database schema. This plan force-includes the
migrations into an importable in-package anchor, adds the missing PEP 561 `py.typed`
marker, and proves the fix with two real (not mocked) integration tests: an actual
`uv build` → fresh venv → `pip install` → `alembic upgrade head` round trip, and a wheel
namelist inspection.

Purpose: PKG-01 — the library must be installable via git-tag pin AND immediately usable
(typed, schema-bootstrappable) by a consumer, not just importable.
Output: `pyproject.toml` packaging fix, `src/availability_engine/migrations.py` +
`_migrations/__init__.py`, `py.typed`, and two `tests/packaging/` integration tests.
</objective>
